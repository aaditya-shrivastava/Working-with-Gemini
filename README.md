# 💬 Chat-Box (Gemini AI Powered)

This project is a simple AI-powered chat application built using **Google Gemini AI Studio API**.  
It allows users to interact with an intelligent chatbot by sending prompts and receiving real-time responses.

---

## 🚀 Features

- 🤖 AI-powered chat using Gemini API  
- ⚡ Real-time response generation  
- 🧠 Context-based conversations  
- 🌐 Simple and clean user interface  
- 🔑 Secure API key integration  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express  
- **AI Integration:** Google Gemini AI Studio API
